# finance_analyst_portfolio

Портфолио с пет-проектами финансового аналитика 

1. **sales_stores** - анализ продаж (Pandas, Excel, csv).
2. **excel_processing** – автоматизация обработки Excel-файла.
3. **file_pacing** – парсер файла через функции и циклы.
4. **hh_analysis** – анализ вакансий финансового сектора (HH.ru) (статус - в работе).
